# وب‌سایت باشگاه مشتریان سرو لایف

پروژه‌ی React + JavaScript برای معرفی اکوسیستم خدمات سالمندی «سرو لایف» وابسته به بنیاد فرزانگان عمارت ماندگار دوران. طراحی بر اساس تصویر مرجع شما، با چیدمان راست‌به‌چپ، رنگ‌های سبزآبی و کرم، کارت‌های گوشه‌گرد و رابط کاربری خوانا برای سالمندان و خانواده‌ها انجام شده است.

## امکانات پیاده‌سازی‌شده

- صفحه‌ی اصلی با معرفی باشگاه، دسترسی سریع و معرفی پنج محور اکوسیستم.
- صفحه‌ی مستقل تأمین کالا با جستجو، فیلتر دسته‌بندی، کارت محصول و فهرست درخواست کالا.
- صفحه‌ی پایگاه دانش با دسته‌بندی مقاله‌ها، پوسترها، کتاب‌ها، فیلم‌های آموزشی و راهنماها.
- صفحه‌ی آموزش با مسیرهای «خانواده سالمندان» و «سالمندیاری»، دوره‌ها و توضیح مسیر گواهی مهارتی.
- صفحه‌ی خدمات تخصصی با مراقبت در منزل، خدمات درمانی در منزل، حمل‌ونقل ویژه و کلینیک‌های تخصصی.
- معرفی ویژه‌ی ون سبز مجهز به بالابر/سامانه جابه‌جایی ویلچر در صفحه‌ی حمل‌ونقل.
- صفحه‌ی مراکز تخصصی با تورهای گردشگری، تفریح و سرگرمی، فعالیت‌های داوطلبانه، اقامت موقت و بازتوانی، نگهداری شبانه‌روزی و مراکز روزانه.
- برای زیربخش‌های اکوسیستم نیز صفحه‌ی توضیحات جداگانه در نظر گرفته شده است.
- فرم درخواست مشاوره، منوی موبایل، جستجوی فروشگاه، سبد درخواست و اعلان‌های رابط کاربری.

## پیش‌نیاز

- Node.js نسخه‌ی ۱۸ یا جدیدتر
- npm

## اجرای پروژه در ویندوز

۱. فایل ZIP را Extract کنید و وارد پوشه‌ی `sarv-life-site` شوید.

۲. در همان پوشه، ترمینال یا CMD را باز کنید و اجرا کنید:

```bash
npm install
```

۳. سپس سرور توسعه را اجرا کنید:

```bash
npm run dev
```

۴. آدرسی که Vite در ترمینال نمایش می‌دهد (معمولاً `http://localhost:5173`) را در مرورگر باز کنید.

برای ساخت نسخه‌ی نهایی قابل انتشار:

```bash
npm run build
```

خروجی نهایی در پوشه‌ی `dist` ساخته می‌شود. برای مشاهده‌ی خروجی build به‌صورت محلی:

```bash
npm run preview
```

## قرار دادن فونت وزیر

فایل فونت وزیر را خودتان در مسیر زیر قرار دهید:

```text
public/fonts/Vazir.woff2
```

در کد، فونت با نام `Vazir` و از طریق `@font-face` در `src/styles.css` تعریف شده است. اگر نام یا فرمت فایل شما متفاوت است، مسیر `url(...)` همان بخش را اصلاح کنید. در نبود فایل فونت نیز فونت‌های جایگزین سیستم استفاده می‌شوند.

## ساختار پوشه‌ها

```text
sarv-life-site/
├── public/
│   ├── fonts/
│   └── images/
├── src/
│   ├── components/       # هدر، فوتر، کارت‌ها، فرم، سبد درخواست و اجزای مشترک
│   ├── context/          # وضعیت سبد درخواست و اعلان‌ها
│   ├── data/             # داده‌های نمونه‌ی اکوسیستم، محصولات، دوره‌ها و صفحات
│   ├── pages/            # صفحات مستقل سایت
│   ├── App.jsx
│   ├── main.jsx
│   └── styles.css
├── index.html
├── package.json
└── vite.config.js
```

## مسیرهای سایت

| مسیر | صفحه |
|---|---|
| `/` | خانه |
| `/shop` | تأمین کالا / فروشگاه |
| `/knowledge` | پایگاه دانش |
| `/education` | آموزش |
| `/services` | خدمات تخصصی |
| `/centers` | مراکز تخصصی |
| `/section/:slug` | صفحه‌ی جزئیات هر زیربخش |

## نکات پیش از انتشار واقعی

این خروجی یک فرانت‌اند قابل اجرا و تعاملی است؛ اما هنوز به سرور، پایگاه داده، پنل مدیریت، درگاه پرداخت، انبار، سامانه‌ی کاربران، پیامک یا سامانه‌ی نوبت‌دهی متصل نیست. در نتیجه سبد کالا و فرم‌ها در این نسخه صرفاً نمایشی و سمت مرورگر هستند. قیمت و موجودی کالا، شماره تماس، آدرس مراکز، برنامه‌ی دوره‌ها و اطلاعات حقوقی/مجوزی باید با داده‌های قطعی مجموعه جایگزین شوند.

تصاویر موجود در `public/images` برای نمونه‌سازی رابط از تصویر مرجع آپلودشده استخراج شده‌اند. برای انتشار عمومی، بهتر است تصاویر اصلی و باکیفیت و دارای مجوز استفاده‌ی مجموعه جایگزین شوند.
